# Cadastro de Funcionários — CREATE e READ

## Pré-requisitos
Node.js instalado. Abra **esta pasta** no VS Code e use o terminal integrado.

## Sequência
1. Abra `cadastro.js`, complete os PASSOS 1–4 do roteiro e salve.
2. Execute `node cadastro.js` e digite quatro funcionários (use a mesma função para pelo menos dois).
3. Confira o arquivo `funcionarios.json` criado automaticamente.
4. Abra `consulta.js`, complete os PASSOS 5–7 e salve.
5. Execute `node consulta.js`; faça testes com ID existente e inexistente e registre evidências.

**Atenção:** o projeto inicial contém trechos incompletos de propósito. O `consulta.js` só terá os dados após gerar o JSON. Reexecutar o cadastro substitui o arquivo anterior. Não coloque dados pessoais reais; use nomes fictícios.
