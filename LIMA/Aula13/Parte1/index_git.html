Comandos Git

git init

Esse comando cria o repositório Git Local

git status

Esse comando checa o status do repositório

git add

Esse comando ira adiciconar esse arquivo em processo de envio

git commit -m

Esse comando representa a confirmação do processo, ou seja, enviar

git log --oneline

Esse comando mostra o log ou registro das evoluções feitas no repositório

git branch

- Branches -

Criando Repositório

Preciso do meu repositório criado no github para dar inicio as configurações de publicação do projeto

Por que não criar o README?

Por que nosso projeto ja possui um historico. Manter o remoto vazio simplifica a conexão e evita históricos diferentes.

git remote add origin - adicionar o repositorio remoto

git remote -v - visualizar conexao remote git

0 que é Origin ?

E um nome convencional dado ao repositorio remoto

git push - envia a branch main, usa o remoto origin e configura o acompanhamento entre branch local e remote

git push -u origin main

git push - Serão ações futuras

git pull - Quando possuimos alterações que ainda não estão no seu computador

Fluxo Completo Diariamente

git pull - Inicio dos trabalhos

git status - Edição do projeto

git add . - Edição do projeto

git commit -m - Edição do projeto

git push - Edição do projeto
